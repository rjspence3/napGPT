## What Worked

### Code review fixes (all 13 applied cleanly)
- Removing the dead server-side `/recall` handler from `engine.ts` was safe: `ChatWindow.tsx` intercepts `/recall` client-side before it ever reaches the API. The MCP scenario `99_recall_command.ts` tests the browser flow and was unaffected.
- `_boostIntervalId: ReturnType<typeof setInterval> | null` stored on Zustand store but excluded from `partialize` (not serialized to localStorage) — clean fix for the interval leak.
- `process.env.NODE_ENV !== 'production'` guards on `window.__nap_store` and `window.__nap_blanket_check` work because Next.js dead-code-eliminates these blocks in production builds.
- Fixing `isTestMode` in `retryFetch.ts` from a module-level constant to a function call was necessary because `window.__nap_test` can be set after module load.

### CI fixes
- Root cause of `10_effort_bands` failure (consistent since Nov 2025): `MockLLM.normalResponses` were 44–68 chars but effort=60 required ≥120 chars. Fix: extend responses to 186–208 chars. Also added dropout detection (`… zzz`) to skip the length assertion if `DropoutProcessor` fired.
- Root cause of Regression Watch crash: `requireLiveEnv()` throws when no API key, but the `try/catch` only logged a warning, leaving `modelMatrix` undefined. Tests checked `LIVE_LLM !== '1'` but not `!modelMatrix?.length`. Fixed in 6 tests.
- `ui-mcp.yml` was using `pnpm` instead of `npm run` — same class of bug fixed in a prior commit (`2e18709`).
- `ui-all.yml` headful matrix was missing `xvfb` — `xvfb-run --auto-servernum` wraps the headful run now.

## What Didn't Work

- `git rm --cached meme_chain_analyzer.db` failed with "pathspec did not match any files" — the file was never committed, so only `.gitignore` needed updating (no `git rm` required).
- Initial `replace_all` for `isTestMode` in `retryFetch.ts` missed two usages with different indentation (`isTestMode &&` pattern vs `isTestMode)` pattern). Required a second targeted replace.
- Test file `tests/unit/nap.behavior.spec.ts` had pre-existing broken imports: `lazinessCurve` and `setTestRandom` were imported from `@/lib/nap/engine` but neither was exported there. Fixed by importing `lazinessCurve` from `@/lib/nap/utils` and removing the dead `setTestRandom` import.
