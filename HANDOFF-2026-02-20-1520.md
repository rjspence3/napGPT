### `e2099b2` — Fix window globals broken by bdaac87
- **Bug introduced in bdaac87**: `window.__nap_store` / `window.__nap_blanket_check` were gated behind `process.env.NODE_ENV !== 'production'`. Next.js dead-code-eliminates this in production bundles — but CI runs tests against a production build (`npm run build`), so the stores were absent. Broke `overlay.spec.ts` (two tests: idle overlay, boost cooldown).
- **Fix**: Changed guard to `isDevelopmentMode() || isTestMode()`. `isTestMode()` reads `NEXT_PUBLIC_TEST_MODE` which is a `NEXT_PUBLIC_` prefixed env var that survives production bundles.
- **Fix**: Added `NEXT_PUBLIC_TEST_MODE: '1'` to the `Build app` step in `ui-tests.yml` so the flag is baked in at CI build time.
